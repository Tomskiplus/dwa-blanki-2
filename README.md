# DWA BLANKI II

Gra przeniesiona z zeszytu do przeglądarki. Na razie gotowy jest ekran tytułowy
z przyciskami **Singleplayer** i **Multiplayer** oraz ozdobnymi kształtami.

## Jak uruchomić

1. Otwórz folder projektu w VS Code.
2. Prawy klik na `index.html` → **Show Preview** (rozszerzenie Live Preview).
3. Albo otwórz `index.html` w przeglądarce.

## Sterowanie

- **Myszka**: najedź i kliknij przycisk.
